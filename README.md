# Accept, please.

一个静态、可部署的中文单页网站：让用户选择科学家、填写论文标题和目标期刊，生成一张带原创矢量头像风格的论文录用祝福卡。

## 本地预览

直接打开 `dist/index.html`，或在项目目录运行任意静态文件服务器即可。

## 已包含

- 响应式单页叙事设计，移动端可用
- 爱因斯坦、牛顿、居里夫人、达尔文、特斯拉五位科学家选择
- 论文标题 / 目标期刊编辑与免费祝福预览
- 祝福卡系统分享、复制文字、SVG 下载
- 按发表目标分级的 ¥0.1 / ¥0.5 / ¥1.2 微支付档位：目标越卷，祝福浓度和登场科学家层次越高
- 支付弹窗已接入支付宝收款码；微信入口保留为待添加，当前是手动扫码模式，不自动核验订单
- 首页主流程为「idea / paper 输入 → 伟大科学家欧气彩蛋 → 支付二维码」，把广告位放在用户刚完成科研产出、正需要情绪价值的时刻
- 支付占位按钮，后续可替换为微信支付、支付宝或 Stripe Checkout
- 清晰的 parody / disclaimer：原创矢量头像，祝福非历史人物真实引语，也不代表任何人物、机构或期刊背书

## 部署

`dist/` 是无构建静态目录，可直接部署到 Cloudflare Pages、Netlify、Vercel Static、GitHub Pages 或任意静态托管。

仓库已包含 `.github/workflows/pages.yml`。推送到 GitHub 的 `main` 分支后，GitHub Actions 会自动把 `dist/` 发布到 GitHub Pages。
